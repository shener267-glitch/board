# 要人警護作戦ボード（Operation Board）

架空のシナリオを前提とした、要人警護の**作戦計画を作成・整理するためのWebツール**です。
ゲームではなく、ユーザー自身が「誰が・いつ・どこで・何をするか」を配置・入力して一枚の作戦ボードとして管理します。

> 実在の要人・施設・警護計画を再現するものではありません。訓練・演習・企画検討などの架空シナリオ用です。

## コンセプト

ユーザーが用意した画像（航空写真・地図・平面図・会場図など）を**背景レイヤー**として表示し、
その上に人物・車両・施設・群衆・区域・ルート・メモなどの**配置オブジェクト**を重ねていく「デジタル作戦ボード」です。
背景画像そのものは編集せず、「背景画像」と「配置情報」を分離して管理・保存します。

## 主な機能

| 分類 | 内容 |
| --- | --- |
| 背景 | PNG / JPG / SVG のアップロード（ボタン・ドラッグ&ドロップ）、拡大縮小・移動・回転・透明度・表示/非表示・ロック。サンプル背景（架空の会場図）付き |
| 配置 | 人物・車両・施設・ポイント・マーカー・メモ（ダブルクリックで直接編集）。人物・車両は縮尺設定（1m＝何px）に基づく実寸サイズ。クリック/タップ配置、パレットからのドラッグ&ドロップ、連続配置 |
| 範囲 | 群衆エリア（矩形・円・多角形、半透明表示、想定人数）、区域（矩形・多角形） |
| 線 | ルート（複数点クリック、頂点ドラッグ編集・追加・削除、開始/終了地点）、矢印、線（破線可）、自由描画、四角形・円 |
| 編集 | 選択・複数選択（Shift/Ctrl+クリック、Shift+ドラッグで範囲選択、Ctrl+A）、ドラッグ移動、サイズ変更、回転、コピー/貼り付け/複製、削除、前面/背面、個別ロック |
| 詳細 | 種別ごとの属性編集（名前・役割・所属・人数・状態・担当・乗員・想定人数・説明・備考…）。種類の候補はユーザーが自由に追加・削除可能 |
| レイヤー | 背景・区域・群衆・ルート・施設/ポイント・車両・人物・その他・メモごとの表示/非表示・ロック、オブジェクト一覧。名前表示は 自動（拡大時のみ・重なりは省略）/すべて/選択中のみ/非表示 |
| タイムライン | 時刻・行動・場所・移動手段・担当・備考。ドラッグ（またはボタン）で並べ替え、時刻順ソート、場所/ルートとの関連付け |
| 連携 | 予定を選ぶと関連する場所・ルートをボード上で強調表示・表示位置へ移動。オブジェクト側から関連予定を確認・追加 |
| 保存 | ブラウザ内（IndexedDB）に保存・一覧・削除。作業中データは自動退避し再読み込み時に復元 |
| 書き出し | 作戦データ JSON（背景画像込み / 配置情報のみ）、PNG 画像、印刷・PDF 保存（ボード画像＋タイムライン＋配置一覧） |
| 操作 | Undo/Redo（Ctrl/⌘+Z、Ctrl/⌘+Shift+Z、Ctrl+Y）、ホイール/ピンチでズーム、ドラッグでパン、スマートフォン対応（タップで選択→ドラッグで移動、大きめの操作ハンドル） |

## キーボードショートカット

| キー | 動作 |
| --- | --- |
| Ctrl/⌘ + Z / Ctrl/⌘ + Shift + Z（Ctrl + Y） | 元に戻す / やり直す |
| Ctrl/⌘ + C / V / D | コピー / 貼り付け / 複製 |
| Ctrl/⌘ + A | 表示中のオブジェクトをすべて選択 |
| Ctrl/⌘ + S | 保存 |
| Delete / Backspace | 選択中を削除（ルート・多角形の入力中は1点戻す） |
| 矢印キー（+Shift） | 1px（10px）移動 |
| Enter / Esc | ルート・多角形の確定 / 取消・選択解除 |
| V / H | 選択ツール / 画面移動ツール |
| + / − / 0 | 拡大 / 縮小 / 全体表示 |

## 開発

```bash
npm install
npm run dev        # 開発サーバー
npm run build      # 型チェック + 本番ビルド (dist/)
npm run typecheck  # 型チェックのみ
npm run lint       # ESLint
npm test           # ユニットテスト (Vitest)
npm run e2e        # 実ブラウザ E2E スモークテスト (要: npm run build、Chromium)
npm run check      # typecheck + lint + test + build
```

E2E は `playwright-core` で Chromium を起動します。パスは `CHROMIUM_PATH` 環境変数で指定できます（既定 `/opt/pw-browsers/chromium`）。

### GitHub Pages で公開する

サーバー不要の静的サイトなので GitHub Pages で動作します（保存データは各利用者のブラウザ内に保存されます）。

1. リポジトリの **Settings → Pages → Build and deployment → Source** を **GitHub Actions** にする
2. `main` ブランチへ push（または Actions タブから「Deploy to GitHub Pages」を手動実行）
3. `https://<ユーザー名>.github.io/<リポジトリ名>/` で公開される

ワークフローは `.github/workflows/deploy-pages.yml`（型チェック・Lint・テスト・ビルド後にデプロイ）。

### 技術構成

- Vite 8 + React 19 + TypeScript 6
- [Konva](https://konvajs.org/) / react-konva — キャンバス描画・ドラッグ・変形ハンドル・タッチ・画像書き出し
- zustand — 状態管理（Undo/Redo 履歴を含む）
- IndexedDB — ブラウザ内保存（外部サービス不使用）
- Vitest + Testing Library + fake-indexeddb — テスト

### ディレクトリ構成

```
src/
  model/        データモデル・定義・ジオメトリ・保存形式の検証 (純粋関数)
  store/        zustand ストア (履歴/Undo・選択・タイムライン等)、ツール定義、アクション
  canvas/       Konva キャンバス (BoardCanvas)、オブジェクト描画、ラベル
  components/   上部バー・ツールパレット・詳細/レイヤー/背景/候補パネル・タイムライン・ダイアログ
  storage/      IndexedDB 保存、ファイル入出力
  export/       JSON / PNG / 印刷 の書き出し
e2e/            実ブラウザ E2E スモークテスト
public/samples/ サンプル背景 (架空の会場図)
docs/           データ形式・進捗
```

データ形式は [docs/DATA_FORMAT.md](docs/DATA_FORMAT.md)、実装状況と今後の課題は [docs/PROGRESS.md](docs/PROGRESS.md) を参照してください。
